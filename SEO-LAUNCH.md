# Lanzamiento SEO — Centro Podológico Ximena Alvarado

## Objetivo
Posicionar la sede real de **Sabana Norte, San José** para búsquedas de alta intención relacionadas con podología y tratamientos del pie, ampliando relevancia regional hacia pacientes de la Gran Área Metropolitana sin crear sedes o ubicaciones ficticias.

## Qué ya quedó implementado en el código

- Metadata individual para las páginas principales.
- Canonical URLs consistentes.
- Sitemap ampliado con páginas de servicios, reserva, FAQ y zonas de atención.
- `robots.txt` con exclusión de API y gestión administrativa.
- Datos estructurados JSON-LD para `WebSite`, `LocalBusiness`, `MedicalClinic`, persona responsable, catálogo de servicios, breadcrumbs y FAQ visibles.
- Páginas indexables específicas para:
  - uña encarnada;
  - matricectomía ungueal;
  - hongos en las uñas / onicomicosis;
  - pie diabético;
  - callosidades y helomas;
  - verrugas plantares;
  - pedicura podológica.
- Página `/zonas-de-atencion` con cobertura regional transparente: sede única en Sabana Norte y atención a pacientes que se desplazan desde San José, Heredia, Alajuela y Cartago.
- Página `/preguntas-frecuentes` con contenido útil para pacientes.
- Enlazado interno entre home, catálogo, páginas de servicio, zonas, FAQ y agenda.
- Open Graph dinámico para mejorar la apariencia al compartir la web.
- Manifest e identidad web.
- Video hero optimizado de aproximadamente 52 MB a aproximadamente 2 MB, más poster WebP ligero.
- Imagen principal de Ximena optimizada a WebP.
- Variables preparadas para Google Search Console.

## Acciones externas urgentes al publicar

### 1. Google Search Console
1. Crear una propiedad de dominio para `centropodologicoximenaalvarado.com`.
2. Verificar el dominio mediante DNS.
3. Copiar el token de verificación en `GOOGLE_SITE_VERIFICATION` si se utiliza verificación por meta tag.
4. Enviar `https://centropodologicoximenaalvarado.com/sitemap.xml`.
5. Usar Inspección de URL y solicitar indexación, en este orden:
   - `/`
   - `/tratamientos`
   - `/quiropodia`
   - `/tratamientos/una-encarnada`
   - `/tratamientos/hongos-unas`
   - `/tratamientos/pie-diabetico`
   - `/tratamientos/callosidades`
   - `/zonas-de-atencion`
   - `/contactenos`

### 2. Google Business Profile
- Usar exactamente el mismo nombre comercial que aparece en la web.
- Mantener teléfono, horario y ubicación consistentes.
- Seleccionar la categoría primaria más específica disponible para podología en Costa Rica.
- Añadir los servicios reales del centro.
- Vincular la web oficial y, si el perfil lo permite, la URL de reserva `/reservar`.
- Publicar fotografías reales del centro, profesional, instrumental y entorno de atención.
- No crear fichas separadas en Alajuela, Heredia o Cartago si no existen sedes físicas allí.

### 3. Reseñas
- Solicitar reseñas a pacientes reales de manera neutral después de la atención.
- No comprar reseñas, no condicionar premios y no solicitar únicamente reseñas positivas.
- Responder de forma profesional y sin revelar información clínica del paciente.

### 4. Consistencia local
Mantener el mismo NAP (nombre, dirección y teléfono) en:
- sitio web;
- Google Business Profile;
- Facebook;
- Instagram;
- directorios locales legítimos;
- perfiles profesionales relevantes.


### 5. Dirección pública y NAP
La web utiliza actualmente **Sabana Norte, San José** porque es la ubicación disponible en el proyecto. Para maximizar SEO local, si el consultorio publica una dirección completa en Google Business Profile, esa misma dirección debe aparecer exactamente igual en la web y en los directorios legítimos. No se debe inventar una calle o número para completar el schema.

### 6. Medición de conversión
Configurar Google Analytics 4 o una solución equivalente para medir al menos:
- clic en **Agendar cita**;
- inicio del flujo de reserva;
- reserva completada;
- clic en WhatsApp;
- clic en teléfono;
- visitas orgánicas a cada página de tratamiento.

El objetivo no es solo aumentar posiciones, sino saber qué consulta orgánica termina generando citas reales.

### Cobertura regional secundaria
La web menciona Heredia, Alajuela y Cartago como **procedencia de pacientes**, no como sedes. La prioridad seguirá siendo posicionar la ubicación real en Sabana Norte y ganar relevancia regional mediante contenido útil, reputación y señales de Google Business Profile.

## Seguimiento
Después de indexar, revisar semanalmente en Search Console:
- consultas que generan impresiones;
- posición promedio;
- CTR;
- páginas con mayor crecimiento;
- errores de indexación;
- Core Web Vitals.

No conviene cambiar títulos y contenido cada pocos días. Primero se debe permitir que Google rastree, procese e indexe la nueva arquitectura y luego optimizar con datos reales de consultas.
